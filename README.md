## Things I've built

### 🗺️ XPLOR *(Team Project)*
An AI-powered platform that takes 2D floor plans and converts them into interactive 3D models. This was a full team effort — I handled [my contributions here](https://github.com/oArchito/XPLOR-Contributions).

### 🛡️ ExamGuard
Online exam system with real anti-cheat — tab-switch detection, rule acceptance flow, auto-submit on violations. Built with JWT auth and a clean backend.

### 🔧 HR Workflow Designer
A production-level React app for designing and simulating modular HR workflows. Drag, connect, configure — then simulate the whole thing.

### 🛍️ EasyShop
Full-stack e-commerce with Stripe payment integration. Standard MERN, done right.
